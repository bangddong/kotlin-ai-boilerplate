## 시나리오 — AI 크레딧 서비스

사용자가 **크레딧을 충전**하고, **AI 평가 요청**(예: 이력서·답변 채점)마다 크레딧이 차감된다.
하루 **무료 체험 슬롯은 선착순**. LLM 은 느리고(수 초) 비싸고 공급사 호출 한도가 있다.

| 항해 원 시나리오 | AI 크레딧 서비스 |
|---|---|
| 포인트 충전·사용 | 크레딧 충전·사용 |
| 특강 선착순 30명 · 중복 신청 1회 | 일일 무료 평가 슬롯 선착순 30 · 같은 요청 중복 1회 |
| 재고 차감 · 잔액 | 크레딧 차감 · **같은 요청 두 번 = LLM 두 번 과금**(멱등성) |
| 인기 상품 캐시 | **같은 입력 → LLM 재호출 0**(응답 캐시) |
| 콘서트 대기열 | **LLM 동시 호출 제한 대기열**(공급사 rate limit) |
| 결제 후 데이터 플랫폼 전송 | AI 사용량 이벤트 → 과금·분석 |
